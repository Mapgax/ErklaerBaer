If these asset folders are ever published, add the full SIL Open Font License
1.1 text next to this notice, as the OFL requires when the font file travels.

Why this font rather than the alternatives, checked 2026-09-09:
  - Deutschschweizer Basisschrift (basisschrift.ch) has no eszett, and needs a
    paid BKZ licence for products used outside Switzerland.
  - Grundschrift (Grundschulverband e.V.) is licensed for non-commercial use
    only and has no accented Latin vowels, which Dutch needs.
  - Berner Basisschrift 1 covers every character this project uses.
