# Mascot identity reference

`chat-mascot.png` is the owner-selected character reference from the ErklaerBaer design review on
2026-09-06. It defines the desired body volume, expressive face, complete arms and legs, teal
neckerchief, magnifying glass, and tactile paper/felt finish.

It is sent to Black Forest Labs once during the bounded concept-art pass. It is not sent to BFL
during daily video production and is not itself a production-ready animation asset. The approved
concept is rebuilt as separated, editable animation layers in the private Rive authoring file.

No third-party brand, franchise character, written text, or photograph of a person is intended.
The repository owner should retain this note with the asset and confirm that use remains compatible
with the applicable image-generation terms before public release.
