# Legacy

The repository began as a single script that rendered one video about atoms and a laser.
It predates the v3 pipeline in `src/erklaerbaer` and shares no code with it.

Both files are kept because they are the project's first work, not because anything builds
on them. Nothing in `src`, `scripts` or `tests` imports from here.

- `create_video.py` — the original standalone renderer.
- `atom_laser.mp4` — the video it produced.
